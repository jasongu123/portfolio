# Jason Gu — project portfolio

Rutgers MQF 2026. Each folder is a self-contained project with its own README.

| Folder | What it is |
|---|---|
| `multistrategy_system/` | Systematic trading system on the Interactive Brokers TWS API (paper): cross-asset trend sleeve, intraday ETF momentum on a published paper's rules, a stock swing book, execution-cost accounting, data ingestion and tests. `research/` holds the project summary and 97 pre-registered trials, including replications of published pairs-trading and statistical-arbitrage methods and an LLM-to-FinBERT distillation of 46,000 SEC earnings releases. |
| `Option Strategy Pricing/` | C++ pricer for European and American vanilla options and two-leg strategies (spreads, straddles, strangles), with Greeks, an implied-volatility solver, a CRR binomial tree, and a regression test. |
| `corporate_bond_model/` | Machine-learning project predicting corporate bond yield to maturity and bid-ask spread with Elastic Net and tree-based models; notebooks plus the written report. |
| `AI Methods Project/` | Deep learning for limit-order-book forecasting: six architectures benchmarked on Binance BTC order-book snapshots, with adversarial and cost stress tests. |
| `portfolio_project/` | Portfolio optimization comparing extreme-value-theory approaches against equal-weight and minimum-variance benchmarks. |
| `ATPM Project/` | Algorithmic trading and portfolio management notebook with per-asset strategy reports across FX, crypto, equity index, and bond futures. |
| `pairs_trading/` | Pairs-trading backtest of NVDA against the other Magnificent Seven names. |
| `AlphaZero/`, `Maze/`, `NLP/` | Coursework: Monte Carlo tree search for a dice game, a Davis–Putnam maze solver, and an n-gram language model. |
