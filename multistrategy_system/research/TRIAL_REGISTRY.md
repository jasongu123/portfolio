`deflated_sharpe.py` can be recomputed with a defensible effective-trial count instead of the
judgmental 6/12/24 range. One row per distinct configuration whose result was looked at.

Conventions: Sharpe convention is stated per row. "Selected" marks the configuration that was
kept. Backfill of trials before 2026-09-04 is pending; the historical sources to reconstruct
them are listed at the bottom.
